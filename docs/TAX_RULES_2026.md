# Податкові правила Ruby Finance — 2026

Перевірено: **12 липня 2026 року**.

Ruby Finance показує інформаційний місячний розрахунок для стандартного
сценарію ФОП на спрощеній системі. Це не податкова консультація і не готова
декларація.

## Показники 2026 року

| Показник | Значення в Ruby Finance |
|---|---:|
| Мінімальна заробітна плата | 8 647,00 грн |
| Прожитковий мінімум для працездатних осіб | 3 328,00 грн |
| Мінімальний ЄСВ за місяць | 1 902,34 грн |
| ФОП 1 — максимальний єдиний податок за місяць | 332,80 грн |
| ФОП 2 — максимальний єдиний податок за місяць | 1 729,40 грн |
| Військовий збір ФОП 1/2 за місяць | 864,70 грн |
| ФОП 3 без ПДВ | 5% доходу |
| ФОП 3 з ПДВ | 3% доходу + ПДВ |
| Військовий збір ФОП 3 | 1% доходу |

Для груп 1 і 2 фактичну фіксовану ставку єдиного податку встановлює місцева
рада, тому користувач може вказати ставку нижче законодавчого максимуму.

## Формули

- ФОП 1/2: `єдиний податок + ЄСВ + 864,70 грн військового збору`.
- ФОП 3, 5%: `дохід × 5% + ЄСВ + дохід × 1%`.
- ФОП 3, 3% + ПДВ: `дохід × 3% + ЄСВ + дохід × 1%`.

Суму ПДВ Ruby Finance **не розраховує** і не включає до поля `total_tax`:
для цього потрібен окремий облік податкових зобов'язань і податкового кредиту.

## Що не враховується автоматично

- пільги, звільнення та особливі статуси;
- підвищені ставки для окремих порушень або перевищення лімітів;
- наймані працівники та пов'язані з ними податки;
- ПДВ;
- строки сплати, борги, пеня та переплати.

Для таких випадків користувач має перевірити розрахунок у бухгалтера або ДПС.
